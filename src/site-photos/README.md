# Фото з галерей obiimy.world

Скрипти, якими 05.10.2026 переглянуто асортимент («чи немає кращих картинок») і завантажено відібрані кадри в `photo/site/`.
Сайт віддає сторінку-перевірку з `defaultHash`; `ow.py` читає з неї назву cookie (`challenge_passed` для сторінок,
`challenge_passed_cat` для каталогу) і повторює запит.

1. `hash.txt` — будь-який рядок (cookie оновиться сам). Запускати з цієї теки.
2. `python3 crawl.py [категорії]` → `cats.json`: товари категорій (`/filter/page=all/`), назва, ціна, картка 400 px.
3. `python3 gal.py` → галереї товарів у розмірі 600 px у `gal/` (для оглядових аркушів) і ціна з `itemprop="price"`.
4. `python3 full.py` → відібрані кадри 1500 px у `photo/site/` (список `pick` у скрипті) і `picked.json` з назвою товару й ціною.

Кампанійні фото на сайті спільні для різних розмірів одного принта: у підписі називаємо принт, а розмір — лише там,
де його видно (хустка 44 × 44 на шиї, пов’язкою). Нічого не генеруємо й не домальовуємо.
