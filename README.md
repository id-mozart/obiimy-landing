# Obiimy — версії преміум-лендингу

Десять версій лендингу для українського бренду шовкових хусток [Obiimy](https://obiimy.world/) (авторські принти художниці Світлани Сніжко, 100% італійський шовк).

| Версія | Файл-джерело | Що всередині |
|---|---|---|
| Garden (мега-арт, 3D) | `garden.html` | Одна WebGL-сцена на весь скрол: частинки-логотип, карусель шовку, тунель, зграя, жовта коробка з тканиною. Джерела у `src/garden.html` + `src/garden.js` |
| Maison (головна) | `maison.html` | Фото-hero, каталог за настроєм, підбір подарунка, довіра, FAQ. Доведена до 9/10 арт-директором і маркетологом (агенти-рецензенти). |
| Journal | `f-journal.html` | Журнал бренду: обкладинка, три фотоісторії, натюрморти, розмова |
| Campaign | `f-campaign.html` | Темні повноекранні образи з хотспотами «shop the look» |
| Lookbook | `f-lookbook.html` | Sticky-фото змінюється разом із текстом про способи носити |
| Studio | `v-studio.html` | Хустка на булавках під вітром, симуляція тканини (WebGL) |
| Noir | `v-noir.html` | Невагомий шовк і 3D-стрічка твіллі (WebGL) |
| Form | `v-form.html` | Хустка падає на форму й драпірується (WebGL) |
| Art | `art.html` | 3D-хустка з реальним принтом, дев'ять станів |
| Classic | `index.html` | Перша класична версія |

## Сторінки товарів

Для кожної версії є приклад сторінки товару в тому ж стилі: `p-<версія>.html` (на сайті — `product-<версія>.html`). Генеруються скриптом `python3 src/build-products.py` з даних про принти; для WebGL-версій замість фотогалереї — 3D-вьюер шовку з рушієм `src/silk-engine.js`.

## Структура

- Файли у корені — джерела (без `<!DOCTYPE>`, у форматі для платформи публікації артефактів).
- `src/` — 3D-движок тканини `silk-engine.js` і шаблони WebGL-версій; `python3 src/build.py` збирає їх у корінь.
- `build-site.py` — збирає готовий сайт у `site/`: кожна версія загорнута в повний HTML-документ, скопійовані `img/`, `photo/`, `tex/`, `brand/`, згенеровані мініатюри і головна сторінка-хаб.
- `site/` — те, що деплоїться (Railway запускає `npm start` → `serve site`).

## Локально

```bash
python3 build-site.py
npm install
npm start
```

## Деплой

Railway: підключити репозиторій, білд Nixpacks підхопить `package.json`; старт-команда `npm start`, порт із `$PORT`.

Фото, тексти про бренд і логотип взяті з obiimy.world; для комерційного використання потрібен дозвіл бренду.

## B2B / корпоративні лендинги

Генератор `src/build-b2b.py` збирає чотири сторінки у стилях основних версій: `b2b-newyear` (Maison — новорічні корпоративні подарунки), `b2b-horeca` (Noir — шовк для уніформи HoReCa, з калькулятором), `b2b-wholesale` (Journal — опт для магазинів, з PDF-лукбуком `src/build-lookbook.py`), `b2b-calendar` (Lookbook — річна програма подарунків). Форми працюють через `mailto:` (статичний сайт). Ціни — роздрібні з obiimy.world; корпоративні умови (мінімальний тираж, документи, терміни, знижки) — пропозиція, яку має підтвердити бренд.

`src/build-products.py` також генерує додаткові сторінки товарів інших типів (твіллі, маска для сну, набір, резинка) у кожному стилі; `src/imgs.py` робить WebP-варіанти 480/800/1200 для `srcset`.
